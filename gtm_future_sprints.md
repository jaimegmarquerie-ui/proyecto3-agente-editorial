# Future GTM sprints — DRAFT (updated 10 Nov 2026)

> These sprints are **next steps after the MVP**, not work already done.
> Source: product briefing v3 (Sprint 1 Validate · Sprint 2 Demand · Sprint 3 Economic impact), rewritten in the official format.
> Economic figures in the briefing are hypotheses, not measured results.

## Sprint 1 — Validate with real bookshops

| Field | Plan |
|-------|------|
| **Goal** | Prove that the dossiers save research time and are bibliographically accurate for real independent bookshops |
| **Target user / buyer** | User #1: the founder's own future bookshop (La Insumisa, Moscardó) + 2 independent bookshops in Madrid (owner or catalogue buyer) |
| **Channel / motion** | Founder-led: use the agent for La Insumisa's opening catalogue; offer a free 4-week pilot through direct visits to ~10 independent bookshops (Usera, Carabanchel, central Madrid) and through the Madrid booksellers' association (to be identified and verified) |
| **Key deliverable** | Working agent with each bookshop's own JSON profile + 4 dossiers per bookshop + short feedback form |
| **Success metric** | Research time per dossier: from ~4 h (manual, to be measured) to ~45 min with the agent, including human review · ≥90% of ISBNs correct for the cited Spanish edition · the founder and ≥1 of 2 external bookshops want to continue |

## ROI scenario (hypothesis, not measured)

| Item | Value |
|------|-------|
| Manual research per dossier | ~4 h (estimate, to be measured in Sprint 1) |
| With the agent (incl. human review) | ~45 min (estimate) |
| Time saved per dossier | ~3 h 15 min |
| Dossiers per month | 4 |
| **Hours recovered per month** | **~13 h** |
| Imputed operating cost of the bookseller's time | 30 €/h (assumption) |
| **Theoretical value** | **~390 €/month** |

The ~390 €/month is an **imputed value of time potentially freed** for counter service, book recommendations and cultural activities. It is **not** additional sales, net profit, incremental revenue or a measured saving, and the 30 €/h is an imputed operating rate, not a net salary. To show real economic ROI, Sprint 1 must measure manual vs assisted time (the 45 min includes human review, not only run time), the agent's tool costs, the human corrections needed and the value generated. No subscription price is assumed.

## Sprint 2 — Understand demand

| Field | Plan |
|-------|------|
| **Goal** | Learn which questions bookshops really ask and which ones the agent cannot answer yet |
| **Target user / buyer** | The pilot bookshops + 3–5 new bookshops |
| **Channel / motion** | Referrals from pilot bookshops; presentation at a bookseller association meeting (to be identified) |
| **Key deliverable** | Request log per bookshop and optional inventory import (CSV) to flag titles already in stock |
| **Success metric** | % of requests answered with ≥2 verified records · number of unanswered or duplicated requests per month · weekly active bookshops |

## Sprint 3 — Economic impact and paid offer

| Field | Plan |
|-------|------|
| **Goal** | Test whether bookshops would pay, and measure impact on sales with their permission |
| **Target user / buyer** | Bookshops that kept using the agent after Sprint 2 |
| **Channel / motion** | Paid monthly plan offered directly to active pilot users |
| **Key deliverable** | Pricing proposal + impact report connecting dossiers to stock and sales data (only with authorisation) |
| **Success metric** | ≥30% of active bookshops convert to the paid plan · measured sales of titles first found by the agent (no attribution claimed without data) |

## Out of scope for these sprints
Automatic purchasing, sales prediction, payments inside the product, scraping private data.
