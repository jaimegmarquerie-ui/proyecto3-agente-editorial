## Evaluation criteria (E) — what earns 1 vs 2

| ID | Outcome | 1 point | 2 points |
|----|---------|---------|----------|
| E1 | Autonomous MVP in justified stack (25% block) | Working MVP, written justification, ≥3 tools, reports generated | Repeatable, polished run; reliable tools; solid trade-offs |
| E2 | Coherent architecture (30% block) | Clear main path, autonomy after trigger, basic errors | Branching, validations and failures handled well |
| E3 | Grounding with retrieval and real APIs | Working retrieval or credible alternative; 3 real tools with basic validation | Grounding quality, retries, clear failures |
| E4 | GTM future sprints | 2–3 sprints with the 5 fields | Realism, metrics, MVP vs post-MVP separation |
| E5 | Documentation and presentation | Clear README, stack, samples, 5–7 min demo | Excellent docs/diagrams, convincing demo |
